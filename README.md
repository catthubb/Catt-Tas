# Catt-Tas

TASes for CattHub. The script pulls the list for whatever area you're in straight from here.

Put files in `TAS/<area>/<tower>.json`. The area folder needs to be the exact name CattHub uses for that place (`Ring1`, `Zone1`, `TimelessManor`...), and the file is named after the tower's acronym from `workspace.Towers`. ToTS is in `TAS/Ring1/ToTS.json`, for example.
