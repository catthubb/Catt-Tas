# Catt-Tas

TASes for CattHub. The script pulls the list for whatever area you're in straight from here.

Put files in `TAS/<area>/<tower>.json`. The area folder needs to be the exact name CattHub uses for that place (`Ring1`, `Zone1`, `TimelessManor`...), and the file is named after the tower's acronym from `workspace.Towers`. ToTS is in `TAS/Ring1/ToTS.json`, for example.

Heads up: Pit of Misery is the one area that exists in both EToH and The Eternal Abyss, and they're different places. EToH's goes in `Pit-of-Misery`, The Eternal Abyss one goes in `TheEternalAbyss-Pit-of-Misery`. Mix them up and the TAS shows up in the wrong game.

Starry Night only exists in The Eternal Abyss. Its TASes go in `TheEternalAbyss-Starry-Night`.
