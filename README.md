# Catt-Tas

TAS files for CattHub.

## Layout

```
TAS/<Ring>/<Tower>.json
```

- `<Ring>` is the area folder name used by CattHub (`Ring0`-`Ring9`, `Zone1`-`Zone10`, `ForgottenRidge`, `GardenOfEeshol`, ...).
- `<Tower>` is the tower's acronym exactly as it appears in `workspace.Towers` (e.g. `ToTS`, `CoLS`, `ToC(L)`).

Example: Tower of True Skill (Ring 1) -> `TAS/Ring1/ToTS.json`
